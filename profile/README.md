## Contribution에 대해

안녕하세요.
저희 프로젝트에 관심을 가져주셔서 진심으로 감사드립니다.

다만, 저희 Repository에는 운영상 제약이 있어 안내드립니다.
본 GitHub Organization은 국민대학교 KMU Capstone Design(졸업 프로젝트)을 위해 진행되고 있는 프로젝트입니다.

졸업 프로젝트 기간이 종료되기 전까지는 팀원을 제외한 외부 사용자의 Issue 등록 및 Pull Request(PR) 제출을 허용하지 않고 있습니다.
이 점 너른 양해 부탁드립니다.

만약 정책에 따라 허용되지 않은 Issue 또는 PR을 등록하실 경우, 접근이 제한될 수 있습니다.

감사합니다.

Hello,
Thank you very much for your interest in our project.

However, we would like to inform you that there are certain restrictions in our repository.
This GitHub Organization is dedicated to a KMU (Kookmin University) Capstone Design (graduation project).

Until the capstone project period is completed, Issues and Pull Requests (PRs) from external contributors (non-team members) are not permitted.
We kindly ask for your understanding.

Please note that submitting unauthorized Issues or PRs may result in access restrictions.

Thank you for your understanding.
